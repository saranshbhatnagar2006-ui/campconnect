# CampusInnovate (CampConnect)

CampusInnovate is a centralized web platform designed for student creators, developers, and designers to share campus project ideas, find teammates, and collaborate across different departments.

---

## 🚀 Features

* **💡 Idea Publishing:** Share project visions, development stages (Idea Phase, Prototyping, MVP Built, Seeking Expansion), and goals.
* **🤝 Team Matchmaking:** Specify exact skill requirements (e.g., Python, React, UI/UX) and weekly hour commitments to recruit peers.
* **🔍 Centralized Dashboard:** Filter and search through active student projects.
* **👤 Student Profile:** Track personal posted ideas and active team collaborations.
* **🛠️ Django Admin Panel:** Full backend integration to securely manage users and project data.

---

## 🛠️ Tech Stack

* **Backend:** Python, Django
* **Frontend:** HTML5, CSS3 (Modern custom design)
* **Database:** SQLite (Default Django database)
